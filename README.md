# 📋 To-Do Flutter App

A collaborative To-Do application built with Flutter + Firebase that supports real-time task sharing, editing, and deep linking.

## 🚀 Features

- Create and manage personal tasks
- Share tasks via Email or WhatsApp
- Real-time sync between users via Firebase Firestore
- Supports deep linking: tap shared links to directly open and edit tasks
- Web editor for non-app users (optional via Firebase Hosting)
- MVVM architecture + Provider for state management
- Responsive UI (mobile/tablet ready)
- Firebase integrated (Firestore, Storage, Dynamic/Deep Links)

## 🛠 Setup Instructions

### 🔧 Prerequisites

- Flutter SDK (3.29.0 or later)
- Firebase CLI (`npm install -g firebase-tools`)
- Android Studio (for running/emulating builds)
- A Firebase project with Firestore enabled
